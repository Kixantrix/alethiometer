# Working on the hardware from a new computer

Everything needed to rebuild the design is in this repo, except two things you supply
yourself: **Myth Made's symbol art** (not redistributable) and the **Freerouting** jar (a
download). Everything git-ignored (`hardware/out/step/`, the assembly STEPs, `viewer/assets/`,
`pcb/fab/gerbers/`, `dial/local/`, `firmware/.pio/`) is regenerated by the steps below.

The hardware work lives on the branch `kixantrix-brass-alethiometer-hardware`.

```powershell
git clone https://github.com/Kixantrix/alethiometer.git
cd alethiometer
git checkout kixantrix-brass-alethiometer-hardware
```

## 1. CAD model (CadQuery)

Last built with Python 3.12, CadQuery 2.8, shapely 2.1, ezdxf 1.4 and VTK 9.6.

```powershell
pip install -r hardware/cad/requirements.txt
cd hardware/cad
python build.py --check   # ~1 min: interference + manufacturability checks only
python build.py           # ~5 min: SendCutSend DXF/STEP, assemblies, renders, report
python plot_flats.py      # flat-pattern previews
```

Every dimension is in `cad/design.py`. Fits and clearances are in its *Tolerance budget*
block, and the plan positions shared with the PCB are in `cad/layout.py`.

## 2. Dial with Myth Made's symbols

1. Download [Myth Made's free alethiometer files](https://mythmade.gumroad.com/l/trhgos) and
   find `Alethiometer Symbols.svg`.
2. Build the dial into the git-ignored `hardware/dial/local/`:

```powershell
pip install fonttools pymupdf pillow numpy
python hardware/dial/make_dial.py --art "$env:USERPROFILE\Downloads\Alethiometer Symbols.svg"
```

Without `--art` you get the website's emoji dial instead. See `dial/README.md`.

## 3. Carrier PCB (KiCad 10 + Freerouting)

1. Install **KiCad 10** (`winget install KiCad.KiCad`) and **Java 17+**
   (`winget install Microsoft.OpenJDK.17`).
2. Download `freerouting-1.9.0.jar` from
   [Freerouting's releases](https://github.com/freerouting/freerouting/releases/tag/v1.9.0).
   Don't use 2.x: its Windows CLI crashes.
3. Run the generator with KiCad's bundled Python. It places the parts from `cad/layout.py`,
   autoroutes, runs DRC and exports `pcb/fab/`:

```powershell
& "$env:LOCALAPPDATA\Programs\KiCad\10.0\bin\python.exe" hardware\pcb\make_pcb.py --freerouting C:\path\to\freerouting-1.9.0.jar
```

You can also set `FREEROUTING` to the jar path instead. If you move a module in `layout.py`,
rerun both this and `cad/build.py`. The committed `pcb/fab/alethiometer_carrier_gerbers.zip`
is ready to order as is.

## 4. 3D viewer

```powershell
python hardware/viewer/export_viewer.py          # rerun after any design.py change
python -m http.server 8765 --directory hardware/viewer
```

Then open <http://localhost:8765>. It needs the same Python packages as step 1.

## 5. Firmware (PlatformIO, ESP32-S3)

```powershell
pip install platformio
$env:PLATFORMIO_CORE_DIR = "C:\pio"     # short path avoids Windows long-path build failures
cd firmware
pio run                                 # build
pio run -t upload                       # flash over USB
```

See `firmware/README.md` for OTA, the serial console commands and calibration.

## 6. Cloud API

The voice endpoints (`/api/ask-voice`, `/api/speak`) live in `api/` alongside the website's
Azure Function. They need Node 24+, two extra Azure OpenAI deployments and a `DEVICE_KEY`
app setting. See *Development* and *Physical instrument API* in the root `README.md`.

## Status and what to check next

Nothing has been built yet. The geometry passes the CAD interference check and the PCB passes
DRC. Before ordering, check these against real parts:

- **USB-C opening.** The receptacle sits about 1.5 mm inside the wall. Hold a real cable up
  to the 12.6 × 6.6 mm opening (`lower_tray()` in `design.py`).
- **X27.168 shaft.** The 38T motor gear sits 5.5 mm above the motor's front face. Check your
  motor's shaft length.
- **Crown switch.** The Omron B3F-3150's button is modelled 3.75 mm above the board
  (`CROWN_SW_ACT_H` in `layout.py`). Check it against the datasheet or a sample.
- **SendCutSend's 8-flange trays** may need manual review (see `BOM.md`).
- **Azure voice endpoints** haven't been run against real Azure deployments.

Board outlines and pin positions for the Adafruit modules (AS5600 #6357, DRV8833 #3297,
MAX98357A #3006, USB-C #4090) were taken from Adafruit's published Eagle files and are coded
into `cad/layout.py` and `pcb/make_pcb.py`.
